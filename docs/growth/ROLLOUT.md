## Experiment register

| Test | Method | Success criterion | Status |
|---|---|---|---|
| Name recall | Show Werkfaden and descriptor to five relevant developers; ask them to type the name later without looking | Record exact spellings and confusion; revise if spelling repeatedly blocks lookup | Not run with people |
| First-screen comprehension | Show only the landing's opening; ask what it does and what it does not prove | Four of five can distinguish project context/change control from an LLM provider | Not run with people |
| First useful query | Eligible testers start from the pinned release and guide, without a live walkthrough | Record time, returned artifact and point of friction; do not invent a time promise | Scripted path exists; human trial not run |
| First verified change | Continue on a small permitted private project | Record exact release and resulting transaction state, with sanitized evidence | No independent cohort result claimed |
| Message comparison | Compare problem-first and mechanism-first posts with the same destination | Compare available impressions/clicks plus volunteered first-use reports; disclose channel/time differences | Drafts only |

These are exploratory usability trials, not statistically powered A/B studies. Do not declare a winning name or conversion uplift from tiny samples. Record denominators and failures as carefully as successes.
